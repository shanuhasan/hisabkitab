# UdhaarHisab — Multi-Tenant Udhaar Management SaaS

## Project Overview
UdhaarHisab is an enterprise-grade, multi-tenant digital udhaar (credit & payment) management SaaS platform built for Indian small shopkeepers and local businesses.

## Key Features
- **Strict Multi-Tenancy**: Complete server-side tenant isolation via global scopes and policies.
- **Precision Ledger Engine**: High-precision `DECIMAL(15,2)` math, atomic database transactions, immutable transaction history, and reversal entries.
- **Indian Business UX**: Mobile-first, bilingual friendly (Hindi/English terminology like "Udhaar Dena" / "Jama Lena"), fast customer search, clean layout.
- **WhatsApp Reminders**: One-tap payment reminders with pre-filled ledger summaries.
- **PDF Account Statements**: Downloadable, printable customer ledger statements powered by DomPDF.
- **Subscription & Super Admin**: Tenant lifecycle management, plans, and usage analytics.

## Tech Stack
- PHP 8.2+
- Laravel 12
- MySQL 8.0+
- Blade & Bootstrap 5.3
- Chart.js & DomPDF
